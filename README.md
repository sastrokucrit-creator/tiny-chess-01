A tiny chess engine in 4 KB of Python — alpha-beta search with quiescence, a transposition table, null-move pruning and a king-safety evaluation, packed into a single 4,089-byte main.py. It plays eight games against a gauntlet of house engines, scored by Elo.

## Run it

```sh
python3 main.py
```
